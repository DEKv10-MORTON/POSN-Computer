🔑 กุญแจสำคัญ: เทียบสัญลักษณ์หารในข้อสอบ (Python vs C++)

ข้อสอบ สอวน. พาร์ทวิทยาการคำนวณชอบใช้ 2 เครื่องหมายนี้หลอกบ่อยมาก ต้องแยกให้ออกครับ:

% (Modulo - หารเอาเศษ)

ใช้ได้เหมือนกันทั้ง Python และ C++
ตัวอย่าง: 14 % 3 = 2 (14 หาร 3 ได้ 4 เศษ 2)

// vs / (หารปัดเศษทิ้ง)

ใน Python ใช้ 14 // 3 = 4
ใน C++ ใช้ 14 / 3 = 4 (ถ้าตัวแปรเป็น int)

ด่านที่ 1: แกะรอยลูปเพิ่มค่าทวีคูณ ระดับ: อุ่นเครื่อง

จงหาว่าเมื่อโปรแกรมทำงานจบ จะพิมพ์ค่าตัวแปร x ออกมาเป็นเลขอะไร?

แนวโจทย์ในห้องสอบ (Python)READ
x = 0
y = 1
while y <= 100:
    y = y * 2
    x = x + 1
print(x)
ร่างจริงในสนามแข่ง (C++)C++
int x = 0, y = 1;
while (y <= 100) {
    y = y * 2;
    x = x + 1;
}
cout << x;
✅ คำตอบที่ถูกต้องคือ: 7

จุดหลอก: หลายคนมักหยุดแค่ตอน y = 64 แต่ 64 ยังไม่เกิน 100 ลูปจึงทำงานต่ออีก 1 รอบครับ

ด่านที่ 2: แปลงเลขฐานสองนับเลข 1 ระดับ: ข้อสอบจริง

หากกำหนดให้เริ่มต้น n = 13 เมื่อจบโปรแกรม ค่าของ count จะเป็นเท่าใด?

แนวโจทย์ในห้องสอบ (Python)READ
n = 13
count = 0
while n > 0:
    count = count + (n % 2)
    n = n // 2
print(count)
ร่างจริงในสนามแข่ง (C++)C++
int n = 13, count = 0;
while (n > 0) {
    count = count + (n % 2);
    n = n / 2;
}
cout << count;
✅ คำตอบที่ถูกต้องคือ: 3

เบื้องหลังอัลกอริทึม: โค้ดชุดนี้คือการแปลงเลข 13 เป็นเลขฐานสอง (13 = 11012) แล้วนับว่ามีเลข 1 กี่ตัวครับ

รอบที่n ก่อนทำn % 2 (เศษ)count สะสมn ใหม่ (n / 2)

2601 + 0 = 13
3311 + 1 = 21
4112 + 1 = 30 (จบการทำงาน)
ด่านที่ 3: ลูปซ้อนลูป (Nested While Loop) ระดับ: ตัวตัดคะแนน

จงหาผลลัพธ์ของตัวแปร s เมื่อลูปซ้อนลูปทำงานจนเสร็จสิ้น

แนวโจทย์ในห้องสอบ (Python)READ
x = 1
s = 0
while x <= 4:
    y = 1
    while y <= x:
        s = s + y
        y = y + 1
    x = x + 1
print(s)
ร่างจริงในสนามแข่ง (C++)C++
int x = 1, s = 0;
while (x <= 4) {
    int y = 1;
    while (y <= x) {
        s = s + y;
        y = y + 1;
    }
    x = x + 1;
}
cout << s;
✅ คำตอบที่ถูกต้องคือ: 20

หลักการมองลูปซ้อน: ลูปนอก (x) กำหนดเพดาน ส่วนลูปใน (y) จะบวกเลขตั้งแต่ 1 ไปจนถึงเพดาน x

ค่า x (ลูปนอก)ค่า y ที่วิ่งในลูปใน (1 ถึง x)ผลบวกที่ได้ในรอบนี้ค่า s สะสม
x = 1111
x = 21, 21 + 2 = 31 + 3 = 4
x = 31, 2, 31 + 2 + 3 = 64 + 6 = 10
x = 41, 2, 3, 41 + 2 + 3 + 4 = 1010 + 10 = 20
