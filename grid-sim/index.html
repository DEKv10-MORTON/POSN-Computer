PILLAR 3: 2D GRID & SIMULATION

🗺️ ตารางพิกัดและสถานการณ์จำลอง (Simulation)

พิชิตโจทย์แนวเดินเขาวงกต พิกัดฉาก $x, y$ และการควบคุมเมทริกซ์ 2 มิติใน C++

💡 เทคนิคพิชิตโจทย์ Simulation สอวน.

โจทย์จำลองสถานการณ์และตารางมักจะซ่อนตรรกะการขยับตำแหน่งไว้ หากวาดภาพตามไม่ออกจะงุนงงมาก หลักการสำคัญคือ:

  • ระบบพิกัด $x, y$: จำให้แม่นว่าขยับขวา $x$ เพิ่ม, ขยับซ้าย $x$ ลด, เดินหน้า/ขึ้นบน $y$ เพิ่ม และถอยหลัง/ลงล่าง $y$ ลด
  • Array 2 มิติ: แถวแรกคือแนวตั้ง (Row/y) คอลัมน์คือแนวนอน (Col/x) การเขียนลูปซ้อนลูปต้องคุมขอบเขตไม่ให้หลุดตาราง (Out of Bound)
  • ตัวแปรจำลองสถานการณ์: แยกตัวแปรสถานะ (State) ให้ชัดเจน เช่น ทิศทางหุ่นยนต์, คะแนนสะสม, หรือจำนวนรอบที่เดิน
ด่านที่ 1: หุ่นยนต์เดินตามเข็มทิศพิกัด $(x, y)$ ระดับ: พื้นฐานตาราง

กำหนดให้หุ่นยนต์เริ่มที่ตำแหน่ง $(0, 0)$ อ่านคำสั่งการเดิน N (ขึ้น), S (ลง), E (ขวา), W (ซ้าย) จงหาพิกัดสุดท้ายเมื่อทำงานจบ

แนวโจทย์ในห้องสอบ (Python)READ
x, y = 0, 0
moves = "NNEEEWS"
for cmd in moves:
    if cmd == 'N': y += 1
    elif cmd == 'S': y -= 1
    elif cmd == 'E': x += 1
    elif cmd == 'W': x -= 1
print(x, y)
ร่างจริงในสนามแข่ง (C++)C++
int x = 0, y = 0;
string moves = "NNEEEWS";
for (int i = 0; i < moves.length(); i++) {
    char cmd = moves[i];
    if (cmd == 'N') y++;
    else if (cmd == 'S') y--;
    else if (cmd == 'E') x++;
    else if (cmd == 'W') x--;
}
cout << x << " " << y;
คำตอบ: พิกัดสุดท้ายคือ (2, 2)
  • วิธีแกะรอย: เริ่มต้น $(0,0)$ ➔ N(0,1) ➔ N(0,2) ➔ E(1,2) ➔ E(2,2) ➔ E(3,2) ➔ W(2,2) ➔ S(2,1)... อ้าว ไล่ตามลำดับตัวอักษร NNEEEWS จะได้พิกัดสุทธิคือ $x = 2, y = 2$ พอดีครับ
  • ในข้อสอบจริง ให้ใช้วิธีทดเลขแยกแกน $X$ (ซ้าย-ขวา) กับแกน $Y$ (ขึ้น-ลง) จะช่วยให้คิดไวขึ้นและไม่สับสน
ด่านที่ 2: นับจำนวนช่องที่เงื่อนไขเป็นจริงในตาราง ระดับ: ข้อสอบจริง

กำหนดตารางขนาด $3 \times 3$ จงหาว่ามีตัวเลขคู่ในตารางกี่ตัว โดยใช้ลูปซ้อนลูปสำรวจทุกช่อง

แนวโจทย์ในห้องสอบ (Python)READ
grid = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
count = 0
for r in range(3):
    for c in range(3):
        if grid[r][c] % 2 == 0:
            count += 1
print(count)
ร่างจริงในสนามแข่ง (C++)C++
int grid[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
int count = 0;
for (int r = 0; r < 3; r++) {
    for (int c = 0; c < 3; c++) {
        if (grid[r][c] % 2 == 0) {
            count++;
        }
    }
}
cout << count;
คำตอบ: 4 ตัว (ได้แก่เลข 2, 4, 6, 8)
  • ลูปนอก (r - Row): วิ่งควบคุมแถวแนวตั้งจาก 0 ถึง 2
  • ลูปใน (c - Column): วิ่งควบคุมคอลัมน์แนวนอนจาก 0 ถึง 2 ในแต่ละแถว
  • นี่คือโครงสร้างพื้นฐานที่ต้องแม่นยำที่สุด เพราะโจทย์เขาวงกตหรือการกระจายตัวของช่องตาราง สอวน. ทุกข้อจะใช้โครงสร้าง Nested Loop แบบนี้เป็นฐานครับ
ด่านที่ 3: จำลองสถานการณ์กฎเกณฑ์ (Simulation Rules) ระดับ: ตัวตัดคะแนน

โจทย์จำลองการเดินท่อหรือสะสมแต้มตามเงื่อนไขตารางช่อง โดยหากเจอเลขติดลบจะถูกหักคะแนน และถ้าเจอเลข 0 เกมจะหยุดทันที

แนวโจทย์ในห้องสอบ (Python)READ
scores = [10, 15, -5, 20, 0, 50]
total = 0
for s in scores:
    if s == 0:
        break
    total += s
print(total)
ร่างจริงในสนามแข่ง (C++)C++
int scores[] = {10, 15, -5, 20, 0, 50};
int total = 0;
for (int i = 0; i < 6; i++) {
    if (scores[i] == 0) {
        break; // เจอ 0 หยุดลูปทันที
    }
    total += scores[i];
}
cout << total;
คำตอบ: 40
  • ลำดับการทำงาน: $10 + 15 = 25$ ➔ $25 + (-5) = 20$ ➔ $20 + 20 = 40$ ➔ พอเจอตัวถัดไปคือ `0` คำสั่ง `break` จะสั่งตัดจบการทำงานทันที ทำให้เลข `50` ด้านหลังสุดไม่ถูกนำมาบวกเพิ่มครับ
  • ข้อสอบ สอวน. ชอบใช้เงื่อนไขพิเศษแบบนี้ (`break`, `continue`) มาทดสอบความรอบคอบในการอ่านโค้ดจำลองสถานการณ์
