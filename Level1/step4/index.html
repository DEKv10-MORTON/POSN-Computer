วงจรรอบสั่งการด้วย Loops (for & while)

สั่งให้คอมพิวเตอร์ทำงานซ้ำๆ อย่างแม่นยำและรวดเร็ว หัวใจสำคัญของอัลกอริทึมและการหาผลรวม/พิมพ์รูปภาพ

step4_loops.cpp 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    // วนลูปทำงาน n รอบเพื่อหาผลรวมตั้งแต่ 1 ถึง n
    long long sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += i;
    }

    cout << "Sum: " << sum << "\n";
    return 0;
}

1. for loop

Fixed Iteration

ใช้เมื่อรู้จำนวนรอบที่แน่นอน ประกอบด้วย 3 ส่วน: (ค่าเริ่มต้น; เงื่อนไขการทำซ้ำ; การเพิ่ม/ลดค่า)

2. while loop

Conditional Loop

ทำซ้ำไปเรื่อยๆ ตราบใดที่เงื่อนไขยังคงเป็นจริง เช่น while (n > 0) เหมาะสำหรับงานที่ไม่ทราบจำนวนรอบแน่ชัด

3. break & continue

Loop Control

break ออกจากลูปทันที ส่วน continue ข้ามโค้ดส่วนที่เหลือไปเริ่มรอบถัดไป

4. Nested Loops

Pattern Drawing

ลูปซ้อนลูป นิยมใช้ในโจทย์ สอวน. สำหรับวาดรูปดาว 2 มิติ หรือประมวลผลตาราง ตารางการทำงานจะเป็น $O(N \times M)$
