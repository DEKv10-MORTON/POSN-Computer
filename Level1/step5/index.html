คลังเก็บข้อมูลและอาวุธลับ (Arrays, Strings & STL Vector)

จัดการข้อมูลชุดใหญ่ จัดเรียงข้อมูล และใช้พลังแห่ง STL (Standard Template Library) เพื่อพิชิตโจทย์ สอวน.

step5_vector_stl.cpp 
#include <iostream>
#include <vector>
#include <algorithm> // จำเป็นสำหรับการใช้งาน sort()
using namespace std;

int main() {
    vector<int> v = {45, 12, 78, 33};

    // จัดเรียงข้อมูลจากน้อยไปมากด้วย sort
    sort(v.begin(), v.end());

    for (int x : v) {
        cout << x << " ";
    }
    cout << "\n";
    return 0;
}

1. Array (อาเรย์พื้นฐาน)

Static Storage

เก็บข้อมูลชนิดเดียวกันหลายๆ ค่าในตัวแปรเดียว เริ่มนับช่องจาก 0 เสมอ (Zero-based indexing)

2. Vector (อาเรย์ยืดหยุ่น)

STL Dynamic Array

อาเรย์มหัศจรรย์จาก <vector> ที่สามารถเพิ่มหรือลดขนาดได้ตามต้องการระหว่างรันโปรแกรม นิยมใช้แทนอาเรย์ปกติใน สอวน.

3. sort() ฟังก์ชันจัดเรียง

<algorithm>

คำสั่งมหัศจรรย์ใช้จัดเรียงข้อมูลในเวลาอันรวดเร็ว ($O(N \log N)$) ด้วย sort(v.begin(), v.end());

4. String Methods

Text Manipulation

จัดการข้อความได้ง่ายขึ้นด้วยฟังก์ชันพ่วงท้าย เช่น s.length() เช็กความยาว หรือการเข้าถึงตัวอักษรด้วย s[i]
