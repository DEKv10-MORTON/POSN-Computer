สมองกลตัดสินใจด้วยเงื่อนไข (Conditionals & Logic)

เปลี่ยนโปรแกรมให้คิดวิเคราะห์ได้ด้วย if-else และตัวเชื่อมตรรกะ เพื่อแยกแยะกรณีต่างๆ ตามโจทย์กำหนด

step3_logic.cpp 
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;

    if (score >= 80) {
        cout << "Grade 4" << "\n";
    } else if (score >= 50) {
        cout << "Grade 3" << "\n";
    } else {
        cout << "Fail" << "\n";
    }

    return 0;
}

1. If - Else If - Else

Branching

ใช้ตรวจสอบเงื่อนไขเป็นลำดับขั้น เมื่อเงื่อนไขแรกเป็นจริง โปรแกรมจะทำในปีกกาและกระโดดข้ามส่วนที่เหลือทันที

2. AND (&&) & OR (||)

Logical Operators

ใช้รวมเงื่อนไขหลายอย่างเข้าด้วยกัน เช่น (x > 0 && x < 10) ต้องเป็นจริงทั้งสองฝั่งถึงจะทำงาน
