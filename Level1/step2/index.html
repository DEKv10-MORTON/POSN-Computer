กล่องเก็บข้อมูลและการรับ-ส่งข้อมูล (Variables & I/O)

หัวใจของการประมวลผลคือการจำข้อมูล C++ เป็นภาษา Strict Type ที่ต้องระบุประเภทตัวแปรให้ชัดเจน และใช้คำสั่ง cin / cout ในการโต้ตอบกับผู้ใช้

step2_variables.cpp 
#include <iostream>
using namespace std;

int main() {
    // เทคนิค Fast I/O เร่งความเร็วสำหรับงานแข่ง สอวน.
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    long long a, b; // จองกล่องรับเลขจำนวนเต็มขนาดใหญ่
    cin >> a >> b;   // รับค่าจากผู้ใช้ 2 จำนวน

    long long sum = a + b;
    cout << "Sum: " << sum << "\n";

    return 0;
}

1. int vs long long

Integer Overflow

int เก็บเลขได้ประมาณ ±2 พันล้าน หากโจทย์ สอวน. ให้เลขเกิน ให้เปลี่ยนไปใช้ long long (เก็บได้ถึง 9×10¹⁸) ทันทีเพื่อกันค่าล้น

2. char & string

Text Types

char เก็บตัวอักษรเดี่ยว 1 ตัวใช้ Single Quote เช่น 'A' ส่วน string เก็บข้อความยาวใช้ Double Quote เช่น "POSN"

3. cin & cout

I/O Streams

cin >> x; รับค่าเข้ากล่อง (ลูกศรชี้เข้า) ส่วน cout << x; แสดงผลออกหน้าจอ (ลูกศรชี้ออก)

4. Fast I/O

Competitive Tip

ios_base::sync_with_stdio(false); cin.tie(NULL); บรรทัดนี้ช่วยปิดการซิงค์ระบบเก่า ทำให้โปรแกรมอ่านไฟล์ Input ขนาดใหญ่รันผ่านในเวลา 1 วินาที
