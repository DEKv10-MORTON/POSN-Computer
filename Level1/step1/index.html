กระดูกงูของ C++ (C++ Skeleton Structure)

ไม่ว่าโค้ดจะซับซ้อนแค่ไหน โปรแกรม C++ ทุกโปรแกรมต้องมี "โครงสร้างบังคับ" นี้เสมอ ถ้าขาดชิ้นส่วนใดชิ้นส่วนหนึ่งไป คอมไพเลอร์จะไม่ทำงาน!

main.cpp 
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, POSN Computer!" << endl;
    return 0;
}

1. #include <iostream>

Header File

กล่องเครื่องมือรับ-ส่งข้อมูล นำเข้าเพื่อให้เราใช้คำสั่ง cout (พิมพ์ค่า) และ cin (รับค่า) ได้

2. using namespace std;

Shortcut

ทางลัดบอกคอมพิวเตอร์ว่า ขอใช้คำสั่งมาตรฐานได้เลย โดยไม่ต้องพิมพ์คำว่า std:: นำหน้าคำสั่ง cout ทุกครั้ง

3. int main() { ... }

Entry Point

ประตูหน้าบ้านของโปรแกรม คอมพิวเตอร์จะเริ่มอ่านและทำงานตามคำสั่งที่อยู่ภายในปีกกา { } นี้ตั้งแต่บรรทัดแรกจนถึงบรรทัดสุดท้าย

4. return 0; และ Semicolon

Syntax Rules

return 0; คือการบอกว่าโปรแกรมทำงานเสร็จสมบูรณ์แล้ว และทุกบรรทัดคำสั่งต้องลงท้ายด้วย ; (Semicolon) เสมอ
