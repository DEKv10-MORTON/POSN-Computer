PILLAR 2: MATH FOR CODING

📐 แปลงสูตรคณิตศาสตร์ให้เป็นโค้ด สอวน.

เทคนิคเปลี่ยนสัญลักษณ์ผลบวก (Summation) และผลคูณ (Product) ให้กลายเป็นลูปในโปรแกรม

🎥 คลังคลิปติวเตอร์ Math for Coding (เลือกหัวข้อ)

💡 สูตรลับการแปลภาษา "คณิตศาสตร์ ➔ โค้ด"

โจทย์ สอวน. มักออกข้อสอบแนวให้หาโปรแกรมที่ตรงกับสูตรอนุกรมทางคณิตศาสตร์ หลักการจำง่ายๆ มีดังนี้:

  • เครื่องหมายผลบวก ($\sum$): ให้ประกาศตัวแปรผลรวม (เช่น total = 0) แล้วใช้ลูปบวกสะสม total = total + สูตร
  • เครื่องหมายผลคูณ ($\prod$): ให้ประกาศตัวแปรผลคูณเริ่มต้นเป็น 1 (เช่น ans = 1) แล้วใช้ลูปคูณสะสม ans = ans * สูตร
  • ขอบเขตลูป: ตัวแปรเริ่มจากตัวล่างของซิกม่า (เช่น $n=3$) วิ่งไปจนถึงตัวบน (เช่น $n \le 10$) และต้องขยับค่าตัวนับ n = n + 1 ทุกรอบ
ด่านที่ 1: แปลงร่างอนุกรมผลบวก (Summation) ระดับ: พื้นฐาน
โจทย์ต้องการคำนวณค่าของ: $\sum_{n=3}^{10} (2n + 1)$

โปรแกรม C++ ใดที่เขียนถูกต้องตามขอบเขตและสูตรข้างต้น?

แนวโจทย์ในห้องสอบ (Python)READ
n = 3
total = 0
while n <= 10:
    total = total + (2 * n + 1)
    n = n + 1
print(total)
ร่างจริงในสนามแข่ง (C++)C++
int n = 3;
int total = 0;
while (n <= 10) {
    total = total + (2 * n + 1);
    n = n + 1;
}
cout << total;
จุดสังเกตที่ต้องเช็กในห้องสอบ:
  • จุดเริ่มต้น (Initialization): ต้องกำหนด n = 3 ตามด้านล่างของเครื่องหมาย $\sum$
  • เงื่อนไขลูป (Condition): ต้องเป็น n <= 10 (รวมตัวที่ 10 ด้วย) ตามด้านบนของ $\sum$
  • การขยับค่า (Increment): ในลูปต้องมี n = n + 1 เสมอ ไม่งั้นจะกลายเป็น Infinite Loop
ด่านที่ 2: แปลงร่างอนุกรมผลคูณ (Product) ระดับ: ตัวตัดคะแนน
โจทย์ต้องการคำนวณค่าของ: $\prod_{i=1}^{29} (2i + 1)$

ระวังตัวแปรเริ่มต้น! หากเป็นผลคูณ ตัวแปรเก็บค่าห้ามเริ่มที่ 0 เด็ดขาด

แนวโจทย์ในห้องสอบ (Python)READ
ans = 1   # ต้องเริ่มต้นที่ 1 เสมอสำหรับการคูณ!
i = 1
while i <= 29:
    ans = ans * (2 * i + 1)
    i = i + 1
print(ans)
ร่างจริงในสนามแข่ง (C++)C++
long long ans = 1; # ใช้ long long เพราะเลขจะโตเร็วมาก
int i = 1;
while (i <= 29) {
    ans = ans * (2 * i + 1);
    i = i + 1;
}
cout << ans;
ทำไมต้องใช้ `long long` ใน C++?
  • เพราะการคูณเลขซ้ำๆ หลายรอบ ค่าผลลัพธ์จะพุ่งสูงขึ้นอย่างรวดเร็ว (Exponential growth) เกินขีดจำกัดของตัวแปรประเภท int ปกติ
  • ใน C++ จึงต้องใช้ long long int เพื่อป้องกันปัญหาค่าติดลบหรือค่าเพี้ยนจากการที่ตัวแปรล้น (Integer Overflow)
ด่านที่ 3: สูตรคำนวณค่าทางคณิตศาสตร์ (Euler's Formula) ระดับ: ข้อสอบจริง สอวน.
จากสูตรออยเลอร์: $\frac{\pi^2}{6} \approx \sum_{k=1}^{n} \frac{1}{k^2}$ ดังนั้น $\pi \approx \sqrt{6 \times \sum}$

การผสมผสานลูปบวกสะสมกับการถอดสแควร์รูท (Math Library)

แนวโจทย์ในห้องสอบ (Python)READ
n = int(input("Enter n: "))
s = 0
k = 1
while k <= n:
    s = s + 1 / (k ** 2)
    k = k + 1
pi = (6 * s) ** (0.5)
print(pi)
ร่างจริงในสนามแข่ง (C++)C++
#include <iostream>
#include <cmath> // เรียกใช้กระเป๋า cmath เพื่อถอดรูท sqrt()
using namespace std;
int main() {
    int n;
    cin >> n;
    double s = 0;
    int k = 1;
    while (k <= n) {
        s = s + 1.0 / (k * k);
        k = k + 1;
    }
    double pi = sqrt(6 * s);
    cout << pi;
}
กับดักหารจำนวนเต็ม (Integer Division Trap):
  • ใน C++ ถ้าเอาตัวแปรประเภทจำนวนเต็มหารกัน เช่น 1 / (k * k) คอมพิวเตอร์จะตัดเศษทศนิยมทิ้งเหลือ 0 ทันที!
  • วิธีแก้: ต้องเขียนเป็น 1.0 / (k * k) หรือใช้ตัวแปรประเภท double เพื่อบังคับให้โปรแกรมคำนวณออกมาเป็นเลขทศนิยมที่ถูกต้องแม่นยำ[cite: 16]
